# References

- **SlickAmogus/silent-hill-decomp (GitHub)** – PC port decompilation of Silent Hill 1. Contains game code and notes on file types (e.g. IPD is type 6).  
- **Vatuu/silent-hill-decomp (GitHub)** – Original Silent Hill PS1 decomp project (engine code only). Useful for function lookups.  
- **belek666/sh_ipd2obj (GitHub)** – IPD-to-OBJ converter written in C. Used as a reference to verify geometry and parsing.  
- **Sparagas/Silent-Hill (GitHub)** – “Silent Hill Hub,” a community repository of file format documentation and tools. Provides general context on RE practices.  
- **Official PS1 Specs** – (for reference) PlayStation endianness and data types.  

*Citations:*  
- File type definitions (from decomp): `.IPD (6) – Map/world geometry chunks`.
